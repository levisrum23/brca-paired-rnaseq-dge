# BRCA Differential Gene Expression Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A reproducible Python pipeline that finds genes and pathways that differ between tumor and normal breast tissue in one public count table, with a 2-page report.

**Architecture:** One script per pipeline step in `src/`, sharing small pure functions that are unit-tested on synthetic data. A single `run_all.py` runs the steps in order. Settings (paths, seed, thresholds) live in one `src/config.py`.

**Tech Stack:** Python 3.11, pandas, numpy, pydeseq2, scikit-learn, matplotlib, seaborn, gseapy, pytest. Environment pinned in `environment.yml`.

**Spec:** `docs/superpowers/specs/2026-10-22-brca-dge-design.md`

## Global Constraints
- Dry-lab only, $0 spend, Python only, public data only.
- Total download under about 50 MB. If no dataset fits, write `BLOCKED.md` and stop.
- Fixed random seed: `SEED = 42` in `src/config.py`.
- Thresholds: `PADJ_MAX = 0.05`, `LOG2FC_MIN = 1.0`. Written in README.
- Never invent accessions, links, checksums or numbers. Every number in `report.md` must come from a file in `results/`.
- Layout is fixed by the spec: `README.md`, `environment.yml`, `data/`, `src/`, `results/`, `report.md`, `tests/`.
- Shared data shapes: `counts` is a `pandas.DataFrame`, rows = samples, columns = gene symbols, integer values. `meta` is a `DataFrame` indexed by the same sample IDs, with column `condition` whose values are exactly `"tumor"` or `"normal"`, plus an optional `patient` column for pairing.

## Review Focus
- Counts file has non-integer values (TPM/FPKM): expect a clear error, not a silent run.
- Duplicate gene symbols (or Ensembl IDs with version suffix): expect them merged by sum or dropped with a logged count, never a crash.
- Samples in counts not in metadata (or different order): expect alignment by ID, and an error naming the missing IDs.
- Zero significant genes: expect empty tables and a clear message, no crash in plots or enrichment.
- Download interrupted or checksum mismatch: expect the partial file removed and a non-zero exit.
